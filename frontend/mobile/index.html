Connectez votre téléphone

Scannez le QR code créé dans POSNIC sur votre ordinateur. Votre téléphone sera associé à votre compte employé sans saisir votre mot de passe.

ou saisir le code
Où trouver le QR code ?
  1. Sur l'ordinateur, ouvrez POSNIC.
  2. Allez dans Paramètres → Mobile POS / Compagnon mobile.
  3. Activez Mobile POS si nécessaire, choisissez l'employé puis générez un code.
  4. Scannez le QR code affiché. Le code est à usage unique et expire après quelques minutes.
